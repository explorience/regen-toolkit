### Correction — a wrong call I made and then disproved

I warned that pushing without the uncommitted `kb-graph/` (2,264 files) and generated `src/data`
JSON would regress the dev site's `/kb/` routes. **That was wrong.**

- `kb-graph/` is a generated **output** — Obsidian companion notes written by `generate-kb-viz.mjs`.
  Nothing under `src/` reads it.
- `prebuild` regenerates every JSON artifact on each build from `data/kb` (clean) and
  `kb-handoff/objects`, so the committed state of those files is irrelevant to the build.
- Proven rather than argued: built the committed state in a clean worktree → 3,931 pages / 4,099
  files, **byte-identical** to the working-tree build across a 394-page sample once asset hashes and
  the org URL are normalized.

**Lesson for next time:** when the question is "would the committed state build differently", build
it and diff, rather than reasoning from which files look uncommitted.
