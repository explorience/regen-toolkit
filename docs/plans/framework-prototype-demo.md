# P3 — Framework Prototype + Group Demo

> **Status:** ready · **Wave:** 2 (the milestone) · **Owner:** Luiz · **Skills:** `superpowers:verification-before-completion`; `/run`, `/verify`
> Part of the [convergence pipeline](CONVERGENCE-PIPELINE.md). **Depends on:** P1 (separation), P2 (real data), D1 (architecture). **This is the "present to the group" gate.**

## Goal
Turn the framework from a doc into **something concrete and graspable** the group (Heenal, Matty, Durgadas, Koi, Rather, Afo) can see and engage — "this is the praxis we've been doing, made real." Concrete beats a 30k-line doc.

## What the prototype IS (assembled from existing pieces)
1. **The live journey site** (`regen-web3-toolkit.vercel.app`) — Heenal's 3 journeys = the framework's public face, instantiated for ReFi.
2. **The org-os layer** — `/initialize` dashboard, the layer docs + canvases, the resource graph (P2 data), the meeting/contribution pipeline — the framework's operating system.
3. **The framework structure made visible** — `framework/README.md` + `SEPARATION.md` + the lifecycle/layer architecture (D1) — the reusable system named.
4. **A one-screen "what this is"** — a short visual/narrative (not the master doc) that a newcomer gets in 2 minutes. Connects to the hub post (P7).

## Phases
1. **Stitch the narrative** — a short deck/page: problem (Durgadas's ToC, P4) → the framework (layers/lifecycle) → the instance (ReFi: site + data) → how others adopt it (RegenOS) → the ask.
2. **Make the org-os layer demoable** — clean `/initialize` dashboard, working canvases, the resource graph populated (P2).
3. **Record/script a 5–10 min walkthrough** (Luiz "is horrible at explaining it" — so make it self-evident: show, don't tell).
4. **Run it by the group** — async (Telegram) + a biweekly slot. Capture reactions → adjust the framework boundary (feeds back into P1).

## Deliverables
- A runnable demo (site + dashboard + framework docs).
- A short "what this is" artifact (the graspable version).
- A group-feedback capture → P1 refinements.

## Definition of done
- The group has seen it and can articulate "framework vs instance" back; ≥1 of Heenal/Matty/Durgadas engages concretely; the framework boundary is validated or corrected.

## Interrelations
- The synthesis point of Wave 1 + P4/P5. Unlocks Wave 3 (P7 hub post reuses the narrative) + Wave 4 (P9 proves adoption). Apply the "don't over-claim" discipline (CSIS, P5) — a prototype, not a finished product.
