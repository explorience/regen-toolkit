# Website Block — Start a Local Node

## Quick Start Process

1. **Join as Network Member**
   - Sign the Community Covenant and join the ReFi DAO Garden.
2. **Prepare your Local Node proposal**
   - Define team, geography, goals, and first deliverables.
3. **Submit on Gardens**
   - Request starter support and complete review process.
4. **If approved**
   - Complete Local Node agreement and activation steps.
5. **Integrate with the network**
   - Introduce your node on Regen Coordination Hub, join channels, and set up Karma GAP.
