# Local Node Onboarding — Quick Start (v0.1)

## Who this is for
- New local node leads and core team members.

## 7-step onboarding flow
1. **Join ReFi DAO Garden + sign covenant**
   - Link: https://app.gardens.fund/gardens/42220/0x4f604735c1cf31399c6e711d5962b2b3e0225ad3/0x13e71c56c5b048e9b8b6a9dbb4a4f346b5dab986
2. **Review agreements + book strategy call**
   - Membership agreement + steward call (Luiz/Monty)
3. **Submit Local Node proposal on Gardens**
   - Include team, timeline, deliverables, budget ask.
4. **Approval gate**
   - Proposal is approved by network process.
5. **Post-approval activation**
   - Complete Local Node Agreement Form.
6. **Identity + channels setup**
   - Telegram, X/Twitter, Farcaster, branded presence.
7. **Integration + reporting setup**
   - Join gated channels, create Karma GAP profile, join forum and events.

## Minimum completion checklist
- [ ] Covenant signed
- [ ] Strategy call completed
- [ ] Proposal submitted + approved
- [ ] Agreement form completed
- [ ] Intro posted on Regen Coordination Hub
- [ ] Channels and branding setup complete
- [ ] Karma GAP profile created

## Evidence to collect
- Garden membership confirmation
- Proposal URL
- Approval proof
- Link to intro post
- Karma GAP profile URL
