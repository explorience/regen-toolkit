# Report Evaluation Checklist (v0.1)

## Structure
- [ ] Includes project information section before activities
- [ ] Activities are standalone blocks (no nested subactivities)
- [ ] Uses consistent formatting and indentation

## Evidence quality
- [ ] Deliverables are real outputs (not just folders/photos)
- [ ] Metrics have source or justified estimate
- [ ] File references are specific and traceable

## Fidelity checks (anti-hallucination)
- [ ] Activities can be traced to source analysis
- [ ] Dates match available evidence or marked as inferred
- [ ] Numbers are evidence-based (or clearly estimated)
- [ ] Suspicious claims flagged for project confirmation

## Actionability
- [ ] Evaluation section contains concrete corrective actions
- [ ] Priorities (high/medium) are assigned
