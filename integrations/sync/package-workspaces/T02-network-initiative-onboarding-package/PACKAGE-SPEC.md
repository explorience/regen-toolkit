# T02 Package Spec

Package: Network Initiative Onboarding Package  
Owner: Luiz (lead)  
Priority: P0  
Date: 2026-03-07

## Scope

### Audience
- Prospective network initiative leads
- ReFi DAO stewards reviewing initiative proposals
- Guild/working group coordinators

### Use cases
1. New initiative wants to join ReFi DAO network — needs pathway from idea to activation
2. Steward needs to evaluate readiness of a proposal — needs alignment checklist
3. Initiative wants to document their governance/funding — needs templates

### In-scope artifacts
- Initiative onboarding pathway (step-by-step)
- Alignment checklist (mission, values, governance fit)
- Funding pathway summary (Gardens flow, reporting expectations)
- Website copy block for ReFi-DAO-Website (network-initiatives page updates)
- Validation checklist (QA for completion)

### Out-of-scope
- Deep governance policy design (reference existing docs)
- Technical build specs (covered by dao-os and other packages)
- Brand/design assets (assumes use of existing ReFi DAO brand kit)

## Target implementation
- regen-toolkit module (content + templates)
- ReFi-DAO-Website community/network-initiatives updates

## Acceptance criteria
- [ ] Reproducible from docs only
- [ ] All links/paths valid at time of publish
- [ ] Metrics defined: proposals submitted, approval rate, time-to-activation
- [ ] Reviewed by at least one current network initiative lead
- [ ] Deployed on ReFi-DAO-Website without breaking existing content
