# Network Initiative Onboarding — Quick Start (v0.1)

## Who this is for
- Leads launching a thematic initiative, guild, or working group inside ReFi DAO.

## 6-step onboarding flow
1. **Become network member**
   - Join Garden and sign covenant.
2. **Apply as core contributor**
   - Submit application and book steward call.
3. **Design initiative proposal**
   - Vision, team, deliverables, budget, impact metrics.
4. **Submit funding proposal on Gardens**
   - Engage community and support process.
5. **Activation if approved**
   - Core contributor hat + initiative recognition + channels.
6. **Ongoing operations**
   - Monthly updates, quarterly impact reporting, governance participation.

## Minimum completion checklist
- [ ] Garden membership complete
- [ ] Contributor application submitted
- [ ] Proposal submitted
- [ ] Proposal approved
- [ ] Initiative channels active
- [ ] Karma GAP profile active
