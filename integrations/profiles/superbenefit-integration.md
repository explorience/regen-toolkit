# SuperBenefit Knowledge Garden Integration (first pass)

## What it is
- SuperBenefit Knowledge Garden: GitHub-hosted knowledge base at [knowledge.superbenefit.org](https://knowledge.superbenefit.org).
- Toolkit sources: E (SuperBenefit Knowledge Garden), O (Reimagining Power case studies).
- Rich DAO patterns, governance, and organizational design content.
- Reimagining Power: real use cases and tested patterns from SuperBenefit practice.

## Why it matters for regen-toolkit
- High-value source for Track 2.7 (Decentralized Governance) and Track 3 (Playbooks, Case Studies).
- Provides concrete DAO patterns and governance frameworks adaptable for local nodes.
- Reimagining Power case studies offer evidence-backed implementation examples.
- Referenced in 260212 planning call as rich DAO patterns source for toolkit synthesis.

## Integration modes
- **Content:** extract DAO patterns, governance frameworks, and Reimagining Power case studies into toolkit modules.
- **Taxonomy:** map SuperBenefit content types (patterns, case studies, governance) to toolkit tracks and canonical concepts.
- **Workflow:** periodic extraction from knowledge garden; convert high-signal artifacts into playbook format.
- **Technical:** align with knowledge garden structure; consider GitHub repo sync if public source available.

## Suggested sync cadence
- **Monthly** content scan of knowledge garden for new/updated artifacts.
- **Quarterly** deep extraction pass for governance and case study modules.
- **Event-driven** when major pattern libraries or case study sets are published.

## Candidate article topics
1. SuperBenefit DAO patterns library for local node implementation.

- Licensing and attribution requirements for SuperBenefit content must be verified.
- Some patterns may be context-specific to SuperBenefit engagements.
