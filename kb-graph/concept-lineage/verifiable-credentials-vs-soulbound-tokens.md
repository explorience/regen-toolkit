# Verifiable Credentials vs Soulbound Tokens

Two credential formats doing the same underlying job (issuer-signed, independently verifiable proof of achievement) via different technical means — VCs as an open cross-platform data format, SBTs as non-transferable NFTs bound to the earning wallet.
