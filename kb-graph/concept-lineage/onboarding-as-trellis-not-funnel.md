# Onboarding as trellis, not funnel

A reframe of member onboarding: a marketing "funnel" treats newcomers as throughput to be converted; a "trellis" is a pre-built structure (a known first-week path, a buddy, a graduation sequence) that's already in place before a newcomer arrives, so integration doesn't depend on the steward's personal, one-off effort each time.
