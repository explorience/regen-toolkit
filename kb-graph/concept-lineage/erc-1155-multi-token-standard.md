# ERC-1155 (Multi-Token Standard)

An Ethereum token standard that handles both fungible and non-fungible tokens within a single smart contract, supporting batch transfers, lower deployment costs, and semi-fungible tokens (e.g. an event ticket that later becomes a collectible).
