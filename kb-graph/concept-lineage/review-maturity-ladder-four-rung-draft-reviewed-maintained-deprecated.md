# Review-maturity ladder (four-rung: Draft / Reviewed / Maintained / Deprecated)

A shippable per-page trust-state label for knowledge commons: Draft (written, unchecked, anyone can edit) -> Reviewed (a second person confirmed accuracy) -> Maintained (reviewed AND someone owns keeping it current, with a review date) -> Deprecated (kept for history, points to its replacement). Stored in page frontmatter (`status`, `reviewed_by`, `last_reviewed`) so it travels with the content.
