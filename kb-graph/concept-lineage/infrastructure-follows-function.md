# Infrastructure Follows Function

Before choosing a knowledge-management tool, ask what work this part of the commons needs to do (explain a concept, inventory resources, track decisions, publish a guide) and pick the substrate that fits that job — not the tool with the nicest landing page. Corollary: no single tool needs to do everything; a healthy commons is usually a hybrid.
