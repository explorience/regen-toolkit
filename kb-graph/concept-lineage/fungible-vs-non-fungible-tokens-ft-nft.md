# Fungible vs Non-Fungible Tokens (FT/NFT)

The foundational token distinction: fungible tokens are mutually interchangeable units of equal value (like currency), while non-fungible tokens (NFTs) are each unique and not interchangeable one-to-one with another of the same type.
