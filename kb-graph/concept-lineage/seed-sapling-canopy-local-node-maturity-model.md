# Seed / Sapling / Canopy local-node maturity model

A three-stage growth model for local (place-based) regenerative-finance nodes: a Seed node is still building its core team; a Sapling has active engagement and real projects; a Canopy node is mature enough to "provide shelter and support" to other nodes. New members are framed as "seedlings" that the onboarding system helps grow.
