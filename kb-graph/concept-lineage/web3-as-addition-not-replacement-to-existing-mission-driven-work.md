# Web3 as addition, not replacement, to existing mission-driven work

A framing that positions web3 tooling as analogous to "your website" — a tool that supports existing work (community relationships, program delivery, physical presence) without replacing it. The recommended adoption pattern: identify a specific current pain point (fundraising, transparency, coordination, or community building), then try one small web3-native intervention rather than a wholesale rebuild.
