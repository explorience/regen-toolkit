# Gas Fee (EIP-1559 Base Fee + Tip Model)

The cost of processing a transaction on a blockchain, expressed as Gas Used × (Base Fee + Tip). Since Ethereum's EIP-1559 upgrade (2021), the base fee auto-adjusts with network demand and is burned; the tip (priority fee) is an optional extra to jump the queue.
