# DAO (Decentralized Autonomous Organization) vs. Local Node

A DAO is a legal-and-technical form (membership, money, and decisions encoded onto a blockchain with verifiable votes); a local node is a community concept (people in a place organized around shared purpose). A node becomes DAO-shaped only when the cost of informality exceeds the cost of the tooling.
