# Typing vs Tagging

Two distinct classification jobs that get confused when treated as one: typing answers "what kind of thing is this?" (a small, stable set — guide, tool, case study, meeting note); tagging answers "what is this about, and how might I want to filter it?" (a large, growing set of topics, domains, audiences).
