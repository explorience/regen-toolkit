# Layered custody (hot/cold/multisig by purpose)

A three-tier custody framework for an organization's crypto holdings: day-to-day operational funds in a hot wallet, reserves/grants in hardware cold storage, and any large organizational transaction gated behind a multi-signature wallet requiring three-or-more approvers.
