# Hybrid web3 adoption (selective tool use by function)

Using web3 tools only where they add clear value (e.g. treasury management, governance voting) while keeping traditional tools where they don't (communication, scheduling, document management), rather than treating "web3 vs. not" as an all-or-nothing choice.
