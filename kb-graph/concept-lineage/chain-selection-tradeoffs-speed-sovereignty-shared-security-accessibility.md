# Chain-selection tradeoffs (speed, sovereignty, shared security, accessibility)

A framework for choosing among non-Ethereum blockchain ecosystems along four axes: raw transaction speed/cost (Solana), full chain sovereignty via custom application-specific chains (Cosmos), shared/borrowed security without running your own validator set (Polkadot parachains, Avalanche subnets), and accessibility/usability for non-technical users (Near).
