# Community-Member Attraction Funnel (Awareness → Interest → Visit → Join)

A four-stage funnel model applied to community building: people discover a node (Awareness, via content/events/referrals), learn more (Interest, via website/docs/conversation), attend (Visit), then commit (Join, becoming members who contribute and stay).
