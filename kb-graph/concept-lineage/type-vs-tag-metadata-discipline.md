# Type vs. Tag (metadata discipline)

A type says what something *is* (a document has exactly one type, e.g. guide, meeting note, decision, person); a tag says how something might be classified or filtered (a document can have many tags, e.g. governance, solar, draft). Confusing the two creates ontology sprawl.
