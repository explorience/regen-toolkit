# Review boundary (consequence-based content tiering)

A written rule sorting knowledge-commons content into tiers by how much damage a wrong or misleading entry does if unchallenged (ephemeral/ personal → working/shared → canonical/load-bearing), with the human review gate applied only where consequence is high.
