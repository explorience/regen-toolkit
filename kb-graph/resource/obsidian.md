# Obsidian

Keeps everything as Markdown files in a folder ("vault") you fully control, with a graph view, backlinks, and a large plugin ecosystem. Named as the fit for "notes and thinking that a few people maintain" — because the files are plain Markdown on disk, the whole vault can be handed to the next maintainer with zero migration. Paid add-on: Obsidian Publish ($10/site/month, or $8/month billed annually).
