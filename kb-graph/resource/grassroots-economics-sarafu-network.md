# Grassroots Economics / Sarafu Network

Runs the Sarafu Network in Kenya — local "community asset vouchers" for trading goods/services when national-currency cash is scarce, now on the Celo blockchain, with feature-phone (USSD) access requiring no smartphone or internet plan. Cited in what-is-blockchain.md as a live community-currency network, with usage figures captured separately as a claim-evidence object (see 08-claim-evidence.yaml).
