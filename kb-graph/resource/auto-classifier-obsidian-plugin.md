# Auto Classifier (Obsidian plugin)

Obsidian plugin (by HyeonseoNam) that classifies notes against three reference modes: all tags in the vault, a filtered regex subset, or a manual hand-curated category list (the supervised "bucketing" pattern, built in). Works with any OpenAI-compatible API (OpenAI, local Ollama, LocalAI) and can also use the Jina AI Classifier, which has a free tier.
