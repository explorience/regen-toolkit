# Logseq

Open-source, local-first notes tool long loved for keeping notes as local Markdown. Cited as a portability caution: it shipped a new SQLite-backed "DB version" in 2025-2026 to fix performance limits on large graphs — faster, but data now lives in a database schema rather than portable text, and the two formats are not interoperable. The article's lesson: "file-on-disk" is a property to keep checking for, not assume, even for historically file-based tools.
