# AI Tagger (obsidian-ai-tagger)

Obsidian plugin for one-click and batch tagging across many LLM providers (OpenAI, Anthropic, Google, Groq, Mistral, local Ollama). Returns up to five tags you've used before and at most three genuinely new ones per note, so existing vocabulary is reused first and novelty is rationed — the article holds this up as a model for a deliberate "new tag" escape hatch reviewed in weekly batches.
