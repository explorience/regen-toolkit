# Astro Starlight

Heavier-duty documentation-site framework: sidebar navigation generated from file structure, dark mode, and built-in full-text search powered by Pagefind that runs entirely at build time (no external service, no API key, no monthly fee). The article notes the Regen Toolkit's own site runs on Starlight — named as the pick when a public commons needs to look and behave like proper docs.
