# Protégé (Stanford ontology editor)

Free, open-source OWL 2 ontology editor from Stanford, ships with reasoners like HermiT. Recommended in ontology-vs-taxonomy.md's "Stretch" exercise: model one real relationship (e.g. "Grant requires Report") and run the reasoner against three real records to test whether an ontology earns its keep before committing to building one.
