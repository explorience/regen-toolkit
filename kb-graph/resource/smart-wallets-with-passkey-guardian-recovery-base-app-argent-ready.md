# Smart wallets with passkey/guardian recovery (Base App, Argent "Ready")

Newer wallet category described in the article: replaces the lone written recovery phrase with passkey sign-in (Face ID/fingerprint) plus recovery via phone backup or trusted "guardians" who can help restore access but cannot spend funds. Named examples: the Base App (Coinbase's wallet, replaced the older Coinbase Wallet in 2025) and Argent (rebranded "Ready" in mid-2025). Grouped as one resource entry since the article treats them as one emerging pattern rather than profiling each separately; no single canonical URL given for the pattern itself.
