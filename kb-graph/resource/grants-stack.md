# Grants Stack

Gitcoin's open tooling for running a QF round end to end (create a program, choose Quadratic Funding, set round basics, payout token and matching pool, optional matching cap/minimum donation/Human Passport requirement, eligibility rules, then launch on-chain). The article frames the hard part as everything around the software — raising a real matching pool, recruiting genuine projects, and driving real donor turnout in a short window.
