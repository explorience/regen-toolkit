# BERTopic

MIT-licensed Python library (Maarten Grootendorst) for embedding-based topic discovery: turns documents into embeddings, clusters them, and labels each cluster with its most distinctive words. Supports guided topic modeling via a seed_topic_list. Article's recommended tool for a one-time "discovery" pass to design a taxonomy, not a daily driver.
