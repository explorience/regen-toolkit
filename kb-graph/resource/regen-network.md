# Regen Network

Blockchain platform issuing science-backed ecological credits, per the article: pays land stewards for measurable ecological work (restored soil, biodiversity) by recording verified ecological data on-chain and issuing purchasable credits. Flagged high_risk because ecological/MRV (measurement, reporting, verification) claims are a standing high-risk trigger — the specific claim that "the regeneration actually happened" is captured separately with a public-use-boundary (see 09-claim-evidence.yaml / 10-public-use-boundary.yaml).
