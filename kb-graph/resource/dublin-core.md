# Dublin Core

Fifteen broad, generic metadata properties (Title, Creator, Date, Subject, Description, Type, Source, Rights, and seven more) standardized internationally as ISO 15836, maintained since the 1990s. Article recommends borrowing its battle-tested field names (e.g. Creator, Subject) rather than inventing new ones.
