# Ollama

Runs open LLMs locally. Article frames running classification through Ollama as more than a cost choice: it keeps unreviewed community material on the team's own machine instead of shipping it to a third-party API — the same public/private boundary the Toolkit's infrastructure layer asks teams to respect for high-risk or sensitive material.
