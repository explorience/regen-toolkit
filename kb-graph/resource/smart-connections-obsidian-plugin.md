# Smart Connections (Obsidian plugin)

Obsidian plugin that builds embeddings entirely on-device, enabling semantic search and chat with a vault fully offline, with nothing sent to the cloud. Article's recommended tool for teams whose commons holds sensitive community data or that want the archive to outlive any one company.
