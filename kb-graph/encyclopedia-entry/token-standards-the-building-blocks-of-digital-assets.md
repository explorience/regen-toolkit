# Token Standards: The Building Blocks of Digital Assets

Compares the three main Ethereum token standards — ERC-20 (fungible), ERC-721 (unique/non-fungible), and ERC-1155 (flexible multi-token) — explaining what each is used for and how a community project (savings tokens, impact credits, marketplaces) should pick between them, framed for East African/Somaliland community and cooperative use cases.
