# An Editorial Workflow Your Commons Won't Outgrow

A concrete editorial workflow for knowledge commons: five stages (Draft, Review, Approve, Publish, Maintain); making trust-state visible on every page (status field or growth labels like seedling/budding/evergreen); separating claims from evidence with a Wikipedia Good-Article-style citation spot-check; using pull requests (and GitBook's change-request equivalent for non-coders) as the review container, with CODEOWNERS auto-assigning reviewers; sorting pages by Diátaxis type (tutorial, how-to, reference, explanation) so reviewers know what "good" means for that page; treating maintenance as an owned, scheduled stage rather than an afterthought; and handling disagreement as a normal, non-violent part of the review process.
