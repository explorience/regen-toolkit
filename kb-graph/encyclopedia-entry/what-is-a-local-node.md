# What Is a Local Node?

A practical guide for people ready to build, defining a "local node" as a place-based community group using Web3 tools and regenerative principles to coordinate real-world action in one specific area — simultaneously self-governing and network-connected. Covers what nodes do (pool resources, fund public goods, onboard newcomers, run a steady meetup cadence, connect outward), when Web3 tooling actually earns its place vs. a spreadsheet, the Localism Fund / quadratic-funding network-funding picture, common structural patterns, a three-stage Seed/Sapling/Canopy maturity model (ReFi DAO), and the single biggest failure mode: bus-factor- of-one burnout.
