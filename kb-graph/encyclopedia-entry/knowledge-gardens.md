# Knowledge Gardens

How to build a community knowledge garden that survives contributor turnover: linking over filing, openly-marked growth stages (seedling/budding/evergreen), and active tending by a named gardener. Uses SuperBenefit's public Knowledge Garden as a worked model (Docs, Lexicon, Links, Patterns) and recommends plain markdown + Git (Obsidian + Quartz + GitHub) as the durable, non-lock-in tool stack.
