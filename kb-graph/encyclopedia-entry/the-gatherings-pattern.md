# The Gatherings Pattern

A five-element framework (Purpose, People, Place, Process, Practice) for designing intentional gatherings for local nodes, plus four ready-made gathering formats (Onboarding, Governance, Trust-Building, Learning) and five cross-cutting hosting principles. Framed as the primary way local nodes build the trust and shared understanding that community finance systems require.
