# AI Tools for Community Knowledge

An opinionated guide to the AI tools that help a small team build a knowledge commons that survives contributor turnover. Organized around one governing rule, "infrastructure should serve the work, not define it" — ask what job needs doing (capture, synthesize, search) before picking a tool. Walks through transcription (Otter.ai) for capture, retrieval-augmented generation (Google NotebookLM) for grounded synthesis, and local-first search (Obsidian + Smart Connections) for private, durable ownership, then closes on three guardrails: privacy, attribution, and naming one steward.
