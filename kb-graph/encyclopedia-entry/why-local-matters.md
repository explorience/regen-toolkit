# Why Local Matters

Argues that place-based nodes do work global protocols structurally cannot: capital is light and can flow anywhere, but trust is heavy and must be built face-to-face over time (the "Ethereum Localism" framing: "what is heavy should be local, what is light should be global and shared" — i.e. subsidiarity). Covers what a node does that a protocol can't (onboarding, deciding which local projects are real, custody/ accountability, the "eight forms of capital" beyond money), the standing network infrastructure a new node can plug into (Greenpill Network, quadratic funding via Gitcoin Grants), the "start small" pattern against building something nobody uses, designing against founder burnout from day one, and concrete tools a node can borrow (Mento/Celo local stablecoins, impactMarket UBI rails, the Regen Coordination Local ReFi Toolkit, BioFi Project templates).
