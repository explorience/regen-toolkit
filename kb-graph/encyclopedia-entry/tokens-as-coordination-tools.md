# Tokens as Coordination Tools

Explains how tokens function as coordination mechanisms for distributed groups: signaling (temperature checks before formal votes), on-chain vs off-chain voting, reputation-based alternatives to pure token wealth, and incentive/penalty design. Walks through MakerDAO, Gitcoin DAO, and KlimaDAO as real examples, then names the recurring failure modes (low participation, wealth concentration, hidden multisig hierarchies, short-termism) and points to the SuperBenefit anticapture framework as a design response.
