# Stewardship Roles for a Knowledge Commons That Outlives You

A guide on naming, assigning, and handing off the five stewardship roles (Editor, Curator, Facilitator, Maintainer, Onboarder) a knowledge commons needs, how to measure fragility via the Contributor Absence Factor (Bus Factor), and how to wire roles into existing tooling (CODEOWNERS, all-contributors, GOVERNANCE.md) so succession survives turnover.
