# Common Pitfalls When Starting a Local Node

Eight recurring failure patterns that sink new local regen nodes/chapters — designing in a vacuum, chasing on-chain tooling before the coordination problem is proven, premature governance theatre, founder burnout, confusing motion with progress, over-isolating or over-attaching to a parent network, and giving up during a natural low-participation dip — each paired with a concrete fix drawn from real projects (Greenpill Network, Grassroots Economics/Sarafu, Compound DAO's Proposal 289, hOurworld).
