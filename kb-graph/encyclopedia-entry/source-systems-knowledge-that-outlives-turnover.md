# Source Systems: Knowledge That Outlives Turnover

Defines a "source system" as a living knowledge environment (wiki, repo, forum, garden…) rather than a one-off link — one that has a steward, keeps getting new material added, and offers a return path to credit and trace claims back to their origin. Contrasts this with a static "link list" that rots. Ties provenance (recorded origin/history) to the principle "inclusion does not mean endorsement," gives real named tools (Obsidian, Logseq, TiddlyWiki, CITATION.cff, ADR/MADR) that already encode these properties, and frames stewardship of a source system as a governance problem (Ostrom's commons-design principles), not just tidying.
