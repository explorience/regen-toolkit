# Layer 2 Solutions

Explains how Layer 2 networks (Base, Arbitrum, Optimism, zkSync Era, Starknet, Scroll) scale Ethereum by processing transactions off the main chain and settling compressed batches back to it, cutting fees from several dollars to fractions of a cent. Covers Optimistic vs. ZK rollup designs, why this matters for regenerative-finance projects running micro-transactions or community token systems, and how to get started (MetaMask, bridging, using L2 dApps).
