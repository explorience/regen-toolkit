# How Web3 Relates to Your Existing Work

A short orientation piece framing web3 as an addition to an organization's existing mission-driven work (community relationships, program delivery, physical presence), not a replacement for it. Offers a pain-point-matching exercise across four areas (fundraising, transparency, coordination, community building) mapping each to a corresponding web3 tool category (crypto donations, blockchain transparency, DAOs/governance tools, tokens/credentials), and recommends starting with one small, reversible use case (a crypto-donate button, a Snapshot vote, a POAP, an on-chain published budget) rather than rebuilding everything.
