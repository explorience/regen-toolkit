# What Is Ethereum?

A beginner explainer for regenerative community builders (written for a Somaliland/East Africa audience) framing Ethereum not as "another cryptocurrency" but as a shared, tamper-proof digital notebook run by thousands of computers with no single controller. Explains smart contracts via a vending-machine metaphor (set conditions, code executes automatically, no middleman), sketches concrete regen use cases (DAO decision-making, transparent fundraising, automatic crop insurance via oracles), and addresses the energy-use objection head-on (Ethereum's 2022 "Merge" cut energy use ~99%).
