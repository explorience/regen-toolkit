# Human Review Boundaries for a Knowledge Commons

Argues that a knowledge commons needs an explicit, written "review boundary" — sorted by the consequence of an entry being wrong, not by its volume or length — so it neither buries reviewers under every edit nor lets unreviewed content masquerade as agreed truth. Proposes a three-tier model (ephemeral/personal, working/shared, canonical/load-bearing), grounds it in Elinor Ostrom's commons-governance principles, and shows how a Git/PR workflow (or a Notion Status property) can make the tool enforce the gate instead of a person policing it.
