## Discussion Summary

### Project Overview
Built on prior Local ReFi Toolkit work from ReFi DAO; FigJam boards for resource mapping already exist; GitHub repo structure established. Motivation: dozens of similar projects across Greenpill, Bankless, regen coordination — this team's stance is "just do it, get it done."

### Content Structure & Approach Debate
- **Tech infrastructure:** GitHub (Luiz) vs Notion (Monty's preference). HackMD as potential bridge. Decision tilts toward GitHub-primary.
- **Content philosophy:** Monty's tools-first (Sylvey playbook, tree planting apps, Atlantis, grass commitment pooling) vs Luiz's comprehensive (multi-audience critical paths, top-down + bottom-up). Open tension; both perspectives kept active.

### Web3 ReFi Tooling Series Integration
Trinity / Matt just completed a web3 ReFi tooling series (publishing Jan 2025) — survey results, community interviews, friction documentation. Could serve as a CTA from toolkit articles ("contribute back" loop).

### Resource Mapping
GitHub already contains 200+ items across ~30 sections. Claude-assisted analysis. Goal: move beyond simple link aggregation → quality assessment, interconnection mapping, status tracking (e.g. Altarus releasing next month).

Practical examples surfaced: Childbirths protocol in Somaliland; multi-sig + wallet setup; Bread Coop's safe setup guide for NGOs; impact attestation workflows.

### Funding & Capacity
- $2.5k currently available; $5k considered "bare minimum to start" by Matt.
- Potential sources: Celo Public Goods, ReFi DAO + Greenpill, Regen Commons (Monty's working group with Patricia / Gregory / Nina, retroactive funding via Gardens pool).
- Capacity: Matt zero-bandwidth (family care, async support), Trinity strategic input, Monty flexible coordination, Luiz primary writing + tech.

### Technical Implementation
GitHub project with track-based organization (Track 1/2/3), source tagging, cross-referencing. Custom front-end planned for non-technical accessibility. Luiz's LiveOS (Obsidian-based, frontmatter-driven) referenced as integration possibility.

### Framing Debate (deferred)
"Regen" (Monty: too broad, not exclusively web3) vs "ReFi" (potentially inaccessible to non-web3, may read as overly financial). Open question.
