# Regen Toolkit — Funding + Pipeline Sync

**Date:** 2026-03-12 (Thursday)
**Type:** Planning
**Source:** Curated by the team in the repo (`docs/meeting-notes/2026-03-12.md`); migrated to canonical org-os layout 2026-04-26. Raw transcript also exists in personal vault as supplementary cross-check.

## Key Decisions

- Apply for **Artisan funding** under a single **Region Coordination** profile that covers both the toolkit AND knowledge-gardening work.
- Use the Greenpill London Artisan application as a template (achieved 5x multiplier prior).
- AI writing pipeline is currently **broken** — needs fixing before resuming mass article production.
- Toolkit's niche framing: **"hyper-specific toolkit for local nodes and chapters"** — let other groups (Gitcoin, Superbenefit, Bioregional Knowledge Commons) handle the broader space. Link out, contribute back, don't duplicate.
- For external content (Gitcoin's new aggregator, etc.): **link rather than copy** when possible; improve where the existing material is shallow.
- Long-term direction: AI-assisted curation that starts highly curated and incrementally lets the community + AI help distill and recommend.

Still in progress; needs more time to finalize. Carry-over from 260225.

### Funding (Artisan, time-sensitive)
The plan is to create one **Region Coordination** profile on Artisan that covers both the toolkit and the knowledge-gardening work — single application instead of two. Greenpill London's prior application (5x multiplier) is the template. Boosts are currently running so this is time-sensitive.

Per the supplementary transcript, the funding model is yield-based: invest money → generate yield → distribute. Resource allocation flexible — "ball's in our court" — with ~50% of region coordination funding going to the current project as the working assumption.

### AI Pipeline Status
The writing pipeline broke a few weeks back, then credits ran out, then more troubleshooting. Currently not producing. Needs Heenal's attention before mass article production can resume.

### Content Plans (Luiz)
- Integrating Safe (smart wallet) content
- Running a workshop next week for ReFi BCN

### Gitcoin's New Aggregator Site
New Gitcoin site brings campaigns, research, mechanisms, case studies into one place. Open question: link to their content or copy in?
- Better to link (avoids duplication)
- Metadata compatibility might be a problem
- Some of their content feels shallow — might warrant improvement contributions

Bigger framing: don't recreate what others are already doing. Link out, contribute improvements back where it makes sense.

### The Vision: Knowledge Federation
We're not alone in this space:
- **Gitcoin** — mechanisms, tools
- **Bioregional Knowledge Commons** — place-based knowledge
- **Superbenefit** — already has an ontology (Rather's, shared in 260225)

Our niche: **hyper-specific toolkit for local nodes and chapters**.

### Luiz's Idea: Co-op Browser Extension
A tool to collectively capture knowledge:
- Add relevant pages via browser extension
- Review together on calls
- Process and integrate into the commons
- Could hook into Green Goods infrastructure

Foreshadows the Coop PL Genesis project (which became active later).

### Long-Term: AI-Assisted Curation (Matt's Dream)
1. Start with highly curated, trusted resources
2. AI helps distill and recommend based on need
3. Build from there — community helps curate
4. Eventually the system runs somewhat autonomously
